# PoE2 시세검색

Path of Exile 2 아이템을 **한글 이름으로 검색**하면 [poe.ninja](https://poe.ninja/poe2) 시세(divine · exalted)를
바로 보여주는 Windows 앱입니다. 영어로 안 바꿔도 한글로 검색하면 끝.

## ⬇️ 다운로드

### 👉 [최신 버전 다운로드 (Releases)](https://github.com/jsh7195/poe2-price-kr/releases/latest)

- **`...-setup.exe`** — 설치본 (**자동 업데이트 지원**, 권장)
- **`...-portable.exe`** — 무설치 (그냥 실행)

---

## 사용법

### 1) 한글로 시세 검색
앱을 켜고 검색창에 한글 이름을 입력하면 시세가 바로 나옵니다.
예) `신성한 오브` · `영혼 핵` · `헤드헌터` · `마법사의 피`

### 2) F9 — 게임에서 아이템 시세 보기
게임 중 아이템에 마우스를 올리고 **`F9`** → 커서 옆에 시세 툴팁이 뜹니다.
poe.ninja에 시세가 없는 아이템이면 `No Item`.

### 3) F10 — 화면 시세 스캔 (조합 · 목록 화면)
아이템 아이콘에 마우스를 올릴 수 없는 **조합/제작/목록 화면**에서는 **`F10`**.
화면을 읽어서 보이는 아이템들의 시세를 **한 번에**(비싼 순) 보여줍니다.

```
┌──────────────────────────┐
│ 1× 보호의 합금     6.26 ◆ │
│ 1× 카오스 오브     5.34 ◆ │
│ 6× 대장장이의 숫돌 1.08 ◆ │   ← 수량 × 단가 합계
└──────────────────────────┘
```

### 4) 트레이 · 업데이트
- 창을 닫아도 **트레이에서 계속 실행**되어 F9·F10이 유지됩니다. (완전 종료: 트레이 아이콘 우클릭 → 종료)
- 헤더의 **업데이트** 버튼으로 새 버전을 확인·적용할 수 있습니다. (설치본)

## ⚙️ 안 되면 이것부터 확인하세요

1. **관리자 권한으로 실행** — 게임이 관리자 권한이면 이 앱도 관리자여야 F9·F10이 동작합니다.
   앱에 뜨는 빨간 **`관리자 권한으로 재실행`** 버튼을 누르거나, exe 우클릭 → **관리자 권한으로 실행**.
2. 게임을 **창 모드 전체화면(Windowed Fullscreen)** 으로 두세요. (독점 전체화면에서는 툴팁이 안 뜹니다)
3. 처음 실행 시 **SmartScreen 경고**가 뜨면 → **추가 정보 → 실행** (서명 안 된 앱이라 정상입니다)

## ❓ 문제 해결

- **F9를 눌러도 아무것도 안 떠요** → 위 1번(관리자 권한)을 확인하세요. 앱 하단에 `⚠ F9 등록 실패`가 보이면
  다른 프로그램이 F9를 점유 중인 것입니다.
- **F10이 "한글 OCR 없음"이라고 떠요** → Windows 설정 → 시간 및 언어 → 언어에서 한국어 언어팩(기본 OCR)을 추가하세요. (보통 한국어 Windows면 이미 있습니다)
- **검색해도 결과가 없어요** → poe.ninja에 시세가 집계되지 않는 아이템이거나, 이름 일부만 입력해 보세요.
