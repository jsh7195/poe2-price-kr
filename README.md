# PoE2 시세검색 (poe2-price-kr)

Path of Exile 2 아이템을 **한글 이름으로 검색**하면 [poe.ninja](https://poe.ninja/poe2) 시세(divine · exalted)를
바로 보여주는 Windows 데스크톱 앱 (Electron).

## ⬇️ 다운로드

### 👉 [최신 버전 다운로드 (Releases)](https://github.com/jsh7195/poe2-price-kr/releases/latest)

- **`...-setup.exe`** — 설치본 (**자동 업데이트 지원**, 권장)
- **`...-portable.exe`** — 무설치 포터블 (자동 업데이트는 안 됨)

> 실행 후 **관리자 권한으로 재실행** 버튼을 누르고, 게임을 **창 모드 전체화면**으로 두세요.
> 서명되지 않은 앱이라 SmartScreen 경고가 뜨면 **추가 정보 → 실행**.

## 왜 만들었나

기존 시세 확인 흐름은 번거로웠습니다.

> poe2db에서 한글로 검색 → 영문 이름으로 바꿔서 확인 → 그 영문을 poe.ninja에 붙여넣기 → 시세 확인

이 앱은 그걸 **한 번으로** 줄입니다.

> 한글 이름 입력 → 시세 끝.

예) `신성한 오브`, `영혼 핵`, `헤드헌터`, `마법사의 피`, `기폭제` …

## 실행

```bash
npm install
npm start
```

## 패키징 / 친구에게 공유

### 방법 A — 폴더 통째로 공유 (지금 바로, 권한 불필요)

```bash
npm run pack   # dist/win-unpacked/ 에 실행 가능한 앱 폴더 생성
```
`dist/win-unpacked` 폴더를 zip으로 압축해 전달하면 됩니다(약 110MB). 친구는 압축을 풀고
**`PoE2 시세검색.exe`** 를 실행 → 빨간 배너의 **"관리자 권한으로 재실행"** 버튼을 누르면 끝.

### 방법 B — 단일 설치파일 / 포터블 exe

```bash
npm run dist   # dist/ 에 설치파일(setup.exe) + 포터블(portable.exe)
```
> ⚠️ 이 단계는 **관리자 권한 또는 Windows 개발자 모드**가 필요합니다(electron-builder가
> 서명 도구를 풀 때 심볼릭 링크를 만듭니다). **관리자 권한 PowerShell** 에서 `npm run dist` 를
> 실행하면 정상 생성됩니다. (개발자 모드 켜는 법: 설정 → 개인정보 및 보안 → 개발자용 → 개발자 모드)

### 친구가 받은 뒤 (중요)
1. 앱 실행 → **관리자 권한으로 재실행** 버튼(또는 exe 우클릭 → 관리자 권한으로 실행)
2. 게임을 **창 모드 전체화면**으로
3. 게임에서 아이템 위 → **F9**

> 서명되지 않은 앱이라 Windows SmartScreen 경고가 뜰 수 있습니다 → **추가 정보 → 실행** 클릭.

## 동작 원리 · 데이터 출처

전부 **공식 데이터**만 사용합니다. poe2db 스크래핑이 없습니다.

| 용도 | 출처 |
|---|---|
| 시세 | poe.ninja PoE2 economy API (`exchange` / `stash` overview) — 공식 JSON, 무인증 |
| 한글 ↔ 영문 사전 | GGG 공식 거래 데이터: 영문(`pathofexile.com`) + 한글(`poe.game.daum.net`) realm |

한글↔영문은 두 realm이 공유하는 **안정적 키**로 조인합니다.
- 통화·소모품류: 항목 `id` 직접 조인 → **100% 커버**
- 유니크: 카테고리별 "유니크만" 인덱스 조인 → **100% 커버**

## ⭐ 인게임 F9 가격체크 (오버레이)

게임을 하다가 **아이템 위에 마우스를 올리고 `F9`** 를 누르면, 커서 옆에 시세 툴팁이 뜹니다.
시세가 없는 아이템이면 **No Item** 으로 표시됩니다.

```
┌─────────────────────┐
│ 마법사의 피  유니크 장신구 │
│ 382  ◈              │   ← divine
│ 34k  ◆   ▲ 379%     │   ← exalted · 7일 변동
└─────────────────────┘
```

동작 방식:
1. 전역 단축키 `F9` (게임이 포커스여도 동작)
2. 포그라운드(게임)에 `Ctrl+C` 전송 → 게임이 호버 아이템 텍스트를 클립보드에 복사
3. 한글 이름을 파싱해 카탈로그에서 시세 조회 → **포커스를 빼앗지 않는 클릭 통과 툴팁**으로 표시
4. 사용자의 원래 클립보드는 복원

> **중요**: F9 는 **게임 창이 활성화(포커스)된 상태**에서 눌러야 합니다. 앱 창이 포커스된 상태로
> F9 를 누르면 게임이 아니라 앱에서 복사되어 "복사 실패"가 표시됩니다.
>
> **권장 설정**: 게임을 **창 모드 전체화면(Windowed Fullscreen)** 으로 두세요. 독점 전체화면에서는
> 어떤 오버레이도 게임 위에 뜰 수 없습니다.
>
> **확실한 수동 방법(자동 복사가 안 될 때)**: 게임에서 아이템 위에 마우스를 올리고 직접 `Ctrl+C`
> → 그다음 `F9`. (게임의 기본 복사 기능을 쓰므로 100% 동작)
>
> **문제 진단**: 터미널에서 `npm start` 로 실행하면 F9 를 누를 때마다 `[F9] copied=… found=…` 로그가
> 찍힙니다. `copied=false` 면 복사 자체가 안 된 것(게임 포커스/권한 확인), `copied=true found=false`
> 면 poe.ninja 미집계 아이템입니다.

## ⭐ F10 화면 시세 스캔 (조합·목록 화면)

조합/제작/목록처럼 **아이템 아이콘에 마우스를 올릴 수 없는 화면**에서는 **`F10`** 을 누르세요.
화면을 캡처해 **Windows 내장 한글 OCR**로 읽고, 인식된 아이템들의 시세를 **한 번에**(비싼 순) 보여줍니다.
각 줄은 **수량 × 단가 합계**로 표시됩니다.

```
┌──────────────────────────┐
│ 1× 보호의 합금     6.26 ◆ │
│ 1× 카오스 오브     5.34 ◆ │
│ 6× 대장장이의 숫돌 1.08 ◆ │
└──────────────────────────┘
```

- 커서가 있는 모니터를 캡처 → OCR → 카탈로그 매칭(OCR 노이즈는 퍼지 매칭으로 흡수)
- 한글 OCR 언어가 없으면 "한글 OCR 없음" 표시 → Windows 설정에서 한국어 언어팩(기본 OCR) 설치
- 게임은 **창 모드 전체화면** 권장(독점 전체화면은 캡처 불가)

## 🪟 트레이 모드

- 창을 닫으면 **트레이에서 계속 실행**되어 F9·F10 이 유지됩니다(트레이 아이콘 우클릭 → 종료로 완전 종료).
- 헤더의 **`▼ 트레이로`** 버튼으로 즉시 트레이로 보낼 수 있습니다.
- 트레이 메뉴의 **`시작 시 트레이로 시작`** 을 켜면 다음 실행부터 창 없이 백그라운드로 시작합니다.

### F9가 안 될 때 (문제 해결)

**가장 흔한 원인 ① — 관리자 권한**: 앱 창이 포커스됐을 때는 F9가 되는데 **게임이 포커스되면 안 된다**면,
게임(PoE2)이 관리자 권한으로 실행 중이고 이 앱은 일반 권한이기 때문입니다. Windows 가 일반 권한 앱의
전역 단축키·입력 전송을 차단합니다.
→ **이 앱을 관리자 권한으로 실행**하세요.
- 개발 실행: **관리자 권한 PowerShell** 에서 `cd C:\dev\poe` → `npm start`
- 빌드된 exe: 아이콘 우클릭 → **관리자 권한으로 실행** (또는 속성 → 호환성 → "관리자 권한으로 실행")

상단에 빨간 안내 배너가 보이면 비관리자 상태입니다(관리자로 실행하면 사라집니다).

**가장 흔한 원인 ② — F9 점유**: 남은 인스턴스/다른 프로그램이 F9 를 점유한 경우입니다.

1. **남아있는 앱 인스턴스를 모두 종료** — 트레이 아이콘 우클릭 → 종료, 또는 PowerShell:
   ```powershell
   Get-Process electron -ErrorAction SilentlyContinue | Stop-Process -Force
   ```
2. 다시 `npm start`. 앱 하단에 **`⚠ F9 단축키 등록 실패`** 경고가 없으면 등록 성공입니다.
3. 상단 **`오버레이 테스트`** 버튼 → 커서 옆에 시세 툴팁이 뜨면 오버레이 정상.
4. 그래도 안 뜨면 로그 확인: `%APPDATA%\PoE2 시세검색\f9-debug.log` 의 마지막 줄.
   - `F9 등록 실패` → F9 점유됨(위 1번)
   - `[F9] fired copied=false` → 복사 실패(게임 포커스/창모드 확인)
   - `[F9] fired copied=true found=false` → poe.ninja 미집계 아이템

> 창을 닫아도 **트레이에서 계속 실행**되어 F9가 유지됩니다. 완전 종료는 트레이 아이콘 → 종료.

## 기능

- 한글/영문 검색 (부분 일치 · 부분 수열 매칭으로 오타·축약 허용)
- 인게임 **F9 가격체크 오버레이** (위 참고)
- **트레이 상주** (창 닫아도 F9 유지) · 단일 인스턴스
- divine · exalted **적응형 표기** (값이 1 div 미만이면 exalted를 기준으로) + 7일 변동률 + 아이콘
- 리그 **자동 감지** + 드롭다운 전환 (현재 시즌: Runes of Aldur)
- 시세 20분 디스크 캐시, 수동 갱신(↻), 한글 사전 7일 캐시
- 커버 카테고리: 화폐 · 조각 · 심연의 뼈 · 미가공 젬 · 혈통 보조 젬 · 에센스 · 영혼 핵 ·
  우상 · 룬 · 징조 · 탐험 · 액체 감정 · 기폭제 · 베리시움 ·
  유니크(무기 · 방어구 · 장신구 · 플라스크 · 부적 · 주얼 · 지도)

## 프로젝트 구조

```
src/
  main/                 메인 프로세스 (모든 네트워크 fetch는 여기서 → CORS 없음)
    config.js           엔드포인트 · 카테고리 매핑(실측 확정)
    ipc.js              IPC 핸들러
    overlay.js          F9 가격 툴팁 오버레이 창 관리
    hotkey.js           전역 F9 단축키 → Ctrl+C → 조회 → 오버레이
    services/
      http.js           fetch 래퍼(타임아웃·재시도·동시성)
      normalize.js      문자열 정규화(검색/조인 공용)
      ninja.js          poe.ninja 클라이언트 + 가치 계산
      dictionary.js     GGG 한글↔영문 사전 빌더
      catalog.js        검색 카탈로그 빌더(+ 변형 dedup)
      search.js         검색 · 랭킹
      cache.js          디스크 캐시(TTL)
      store.js          상태 보관 · 캐시 · 갱신 · priceCheck
      itemtext.js       클립보드 아이템 텍스트 파싱(한/영)
      sendcopy.js       PowerShell SendKeys 로 Ctrl+C 전송
  preload/preload.js    메인 창 contextBridge 안전 API
  overlay/              가격 툴팁 UI (overlay.html · overlay.css · overlay.js · preload.js)
  renderer/             검색 UI (index.html · styles.css · app.js)
```

## 주의

- 인터넷 연결이 필요합니다.
- poe.ninja에 시세가 집계되지 않는 아이템(예: 일부 스킬 젬)은 결과가 없을 수 있습니다.
- 보안: `contextIsolation` + `sandbox` + CSP 적용, 렌더러는 화이트리스트된 IPC만 호출합니다.
